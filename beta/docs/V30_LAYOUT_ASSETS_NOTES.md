# Wikaru v30 — Layout and Assets

- Ikon Badung memakai aset WebP transparan baru yang mengikuti komposisi referensi: matahari jingga, Pura Uluwatu, tebing ungu, tangga batu kiri, semak, dan bulan sabit.
- Cursor desktop memakai sprite v30 dengan penunjuk panah yang jelas pada seluruh delapan state seal.
- Halaman kuis diperhalus untuk desktop, iPad, dan mobile: header lebih tenang, ukuran ikon konsisten, teks persona ringkas, dan daftar suara mobile dapat dibuka/tutup.
- Tombol Contoh Kalimat memakai Kotoba Marks `notes`, timer memakai `timer`, mikrofon memakai `speech`, dan panduan memakai `guide`.
- Copy persona Indonesia diseragamkan menjadi **Hangat & keibuan**, **Manis & ceria**, **Rendah & memikat**, serta **Tenang & berwibawa**.
- Semua entry point memakai build `20260902-final33` dan service worker memakai cache `v32-home-preserved`.
- Tiga konsep beranda tetap berupa mockup dan tidak diterapkan; beranda produksi dipertahankan tanpa perubahan.
- Lapisan profesional v32 hanya menargetkan halaman non-beranda dan dialog. Struktur beranda dikunci dengan hash baseline v30.
